Quick Food is a responsive and modern food delivery platform designed to help local food vendors, home chefs, and small restaurants who are unable to onboard on platforms like Zomato or Swiggy. 🌍
This project gives them a digital presence and helps them reach customers in their local area with ease and simplicity. 💡

🌟 Overview

Quick Food bridges the gap between local sellers and food lovers. It provides an intuitive interface where users can:
	•	Explore nearby food vendors 🥗
	•	Browse dynamic menus 🍕
	•	Add favorite dishes to the cart 🛒
	•	Place orders and make secure payments 💳

The platform is built with HTML, CSS, and JavaScript, ensuring a lightweight, fast, and mobile-friendly experience. 📱

✨ Key Features

✅ Vendor-Friendly Platform: Designed especially for small vendors who can’t list on big platforms.
✅ Beautiful UI/UX: Clean, modern, and responsive design that adapts to all screens.
✅ Dynamic Menu System: Users can browse and filter food items easily.
✅ Interactive Cart: Add, remove, and view total prices in real time.
✅ Order Section: Simple order flow for a smooth customer experience.
✅ Fast & Secure: Optimized frontend and secure order handling.
✅ No Heavy Backend: Uses JavaScript logic and can be extended with a backend later.
